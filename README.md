# One Line, No Deadline Met

An entry for the make.fun bounty [One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce): a single-line joke excusing a missed deadline, capped at 200 characters, judged head to head by an AI comedy editor.

## How it runs

`main.ts` (Node 22, standard library only) copies the shipped `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is not set), byte for byte. The line in `entry.txt` is the whole entry:

> Sorry it's late — I treated the deadline like a terms-and-conditions page: scrolled right past it and clicked 'agree' on a date I never read.
